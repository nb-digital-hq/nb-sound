# Glosario

> **Estado:** Aplicable.

| Término | Significado |
|---|---|
| **Agregado** | Un componente grande y opcional (un modelo o la aceleración por GPU) que se instala con un clic desde Ajustes ([ADR-006](../adr/006-add-ons.md)) |
| **Canalización** | El recorrido de un archivo al importarlo: validar, identificar, decidir, organizar, etiquetar ([catalogación](catalog.md)) |
| **Carpeta de tu música** | La única carpeta que NB Sound gestiona; las rutas de las canciones se guardan relativas a ella |
| **Camelot** | La rueda de tonalidades que usan los DJ para mezclar en armonía |
| **Contrato móvil** | El protocolo `1` entre NB Sound y NB Sound Mobile ([contrato móvil](mobile-contract.md)) |
| **Guardián** | Un script de `scripts/` que hace cumplir una regla de forma automática (`pnpm guardianes`) |
| **Huella acústica** | La firma de `fpcalc` (Chromaprint) que AcoustID usa para reconocer una canción |
| **Huella de contenido** | El SHA-256 del primer y el último MB de un archivo; identifica el archivo aunque cambie de nombre |
| **Instrumental** | La canción sin la voz, que prepara el karaoke |
| **LUFS** | Unidad de sonoridad de EBU R128; NB Sound iguala las canciones y lleva los mashups a −14 LUFS |
| **Mashup** | Una pieza nueva hecha con fragmentos de varias canciones ([mashups](mashups.md)) |
| **Por revisar** | Los archivos que no entraron solos, agrupados por motivo, esperando una decisión |
| **Puerta de red** | `net.rs`, el único sitio por el que algo sale a internet ([red](network.md)) |
| **Sesión** | Lo que arma el DJ Privado: canciones encadenadas con transiciones ([DJ](dj.md)) |
| **Sin verificar** | Una canción importada tal como estaba, sin confirmar sus datos con ninguna fuente |
| **Stems** | Las cuatro partes de una canción separadas por el modelo: voz, batería, bajo y el resto |
| **Tumba** | El registro de algo borrado, para que el teléfono también lo borre |

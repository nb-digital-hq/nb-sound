# Atajos de teclado

> **Estado:** Implementado. Ningún atajo de una sola tecla actúa mientras se escribe en un campo.

| Tecla | Qué hace |
|---|---|
| Espacio | Reproducir o pausar |
| Flecha izquierda / derecha | Diez segundos atrás o adelante |
| Flecha arriba / abajo | Canción anterior o siguiente |
| S | Aleatorio |
| R | Repetir (la cola, una canción, nada) |
| L | Letras |
| F | Reproducción ampliada |
| K | Karaoke |
| D | Sorpréndeme |
| + y - | Volumen |
| Ctrl+Q | La cola |
| Ctrl+M | Minirreproductor |
| Ctrl+K | Buscar |
| F11 | Pantalla completa |
| Escape | Salir de la pantalla completa, de la reproducción ampliada o de la búsqueda |
| Alt+Arriba / Alt+Abajo | Mover una canción en la cola |
| Enter | Reproducir la canción con el foco |
